# 学习模式与产物规格

## 模式总览

| 模式 | 流水线 | 时长 | 适用 |
|---|---|---|---|
| quick | storm → brief → core20 → quiz → feynman → cheatsheet | 约 2.5 小时（一次会话） | 想快速建立全景、能上手 |
| standard | 完整 10 步 | 一周（分 2-3 次会话） | 真想掌握 |

## 共同底线

- 输入类阶段（1-6）可压缩、可裁剪；输出类阶段（7-10）只压缩轮数/时长，绝不砍掉动作。
- 输出动作：动手练（7）、被考（8）、讲出来（9）、压成速查表（10）。
- 产物中必须有「用户的产出」（练习记录/答案/复述原文），AI 写的只是教材。

## quick 压缩规则与时间盒（共约 150 分钟）

| 阶段 | 时间 | 压缩规则 |
|---|---|---|
| storm | 0-25' | 5 视角 × 只给核心立场 1 句 / 最强证据 1 条 / 独家信息 1 条 |
| brief | 25-40' | 60 秒总结 + 3 条发现（标可靠性）+ 1 条行动建议 + 1 个坑 |
| core20 | 40-65' | 核心 20% 清单 + 3 个必做小练习（做完才算过） |
| quiz | 65-85' | 5 题（初 2 / 中 2 / 高 1），逐题交互打分 |
| feynman | 85-105' | 1-2 轮：讲一遍 → 指洞 → 重讲关键点 |
| cheatsheet | 105-130' | 一页速查表（必交付） |
| 缓冲 | 130-150' | 用户提问 / 决定是否升级 |

时间不够时的最小动作（按此顺序压缩，7-10 永不删除）：
1. quiz 减到 3 题；
2. feynman 只做 1 轮；
3. core20 只列清单、留 1 个练习；
4. 缓冲时间全部取消。

## standard 全量规则

- 完整 10 步按顺序执行，每阶段不限时，以产物质量为标准。
- conflict/review/resources/ladder 只存在于 standard。
- quiz 考满 10 题，feynman 循环到简单、准确、完整为止。

## 产物文件规格

| 文件 | 内容规格 |
|---|---|
| 01-storm.md | 5 视角 × 核心立场 / 最强证据 / 独家信息 |
| 02-conflict.md | 冲突点、证据强弱、关键问题、共识、盲区 |
| 03-brief.md | 60 秒总结 + 关键发现（标可靠性）+ 行动建议 +（standard 另有隐藏关联、前沿问题） |
| 04-review.md | 逐条可靠性打分 + 弱结论验证需求 + 视角偏差 + 评分与改进 |
| 05-resources.md | 5 资源（为什么强/怎么用/多久/拿走一个点）+ 被高估的坑 + 一周路径 |
| 06-ladder.md | 5 级阶梯（每级 8 要素） |
| 07-core20.md | 核心 20% 清单 + 练习/小项目 + 用户的练习记录 |
| 08-quiz-log.md | 逐题得分 + 强弱项 + 复习计划 |
| 09-feynman-log.md | 用户复述原文 + 补的洞 + 最终版讲解 |
| 10-cheatsheet.md | 一页速查表（定义/核心条目/场景/易错/检查清单/快问快答） |

## 升级路径

- quick 完成后想升级：运行 `python scripts/session.py upgrade`，模式转为 standard，已完成的阶段保留，从缺失的第一个阶段（conflict）继续。
- 产物文件是升级的输入：conflict 用 01-storm.md，review 用 03-brief.md，资源与阶梯直接产出。
